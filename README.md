# AI 產業鏈追蹤

由消費者向上游推導的 AI 產業鏈單頁網頁：前沿模型、算力架構、台灣供應鏈與硬體瓶頸。
內容依據《AI 產業鏈研究報告》第五版（資料截至 2026-10-31，整理：Michael Liang）。

> 本專案為產業研究整理，不構成投資建議，不提供買賣評等或目標價。

## 這個倉庫裡有什麼

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 唯讀發佈版。單一檔案、無外部程式依賴，只在顯示字型時載入 Google Fonts。 |
| `README.md` | 本文件。 |

`index.html` 不含資料庫、登入、權杖或任何寫入功能，所有訪客只能閱讀。

## 頁面功能

1. **層級總覽**：各層公司數與狀態占比，並顯示資料完整性檢查。
2. **公司表**：依層級、區域、狀態、AI 暴露篩選，可依代號、名稱、層級、狀態、期間、來源日期排序。
3. **季度追蹤**：單家公司的歷季數字與指引。
4. **指標區**：CSP 資本支出、HBM 市占、CoWoS 月產能、MLCC BB 值、ABF 供需缺口等，附更新日期與來源。
5. **變更紀錄**：唯讀版只顯示初始建檔。
6. **報告全文**：第五版完整內容，含目錄與圖片。

## 資料模型

每家公司一列。

| 欄位 | 說明 |
| --- | --- |
| `id` | 股票代號或英文代碼；報告未給代號者以 `TW-名稱` 表示 |
| `name`、`region` | 名稱；區域（台、美、日、韓、歐、中） |
| `layer` | L0–L8、6A–6I、7a–7e、8a–8d |
| `role` | 在產業鏈中的角色 |
| `latest_period`、`period_type` | 最新期間與口徑（季報、半年報、月營收、預告值） |
| `currency`、`numbers` | 幣別；營收、YoY、毛利率、EPS（含單位） |
| `guidance`、`key_note` | 指引、備註 |
| `status` | 已查原文、二手報導、AI摘要、預告或初步值、名單待查、範圍外 |
| `source_url`、`source_date`、`source_basis` | 來源網址、來源日期、來源類型 |
| `ai_exposure`、`ai_reason` | AI 暴露（高、中、低、未評）與理由 |
| `history` | 歷季紀錄，每季新增一筆，不覆寫舊值 |

### 資料處理規則

- 幣別（台幣、美元、日圓、韓元、人民幣、歐元）與期間口徑分開記錄，不同幣別或口徑的數字不可直接比較，因此公司表不提供依營收排序。
- 推算值須註明推算方式；公司自述標為「公司說法」。
- 來源優先順序：交易所或 SEC 公告 > 公司法說簡報 > 媒體轉載 > AI 摘要。
- AI 暴露只在報告有明確占比時評為高、中、低，其餘為「未評」。
- 7a–7e、8a–8d 的子層分法是整理時的假設，報告本身只分到 L7、L8。

## 已知限制

- **列數與規格不同**：報告第十三章廠商地圖去重後共 176 列（台灣 139、海外 33、中國 4）。規格目標為 178 列（台灣 148、海外 26、中國 4）。報告沒有完整的 178 列名單，頁面未用虛構列補數，完整性檢查會顯示差異。
- 報告沒有逐列的來源網址與來源日期，這兩欄在基準資料中為空。
- 報告沒有 DRAM 合約價與 1.6T 出貨量的數字，指標區標示「未揭露」。
- 多數數字來自媒體轉載的券商與研究機構報告；報告所述僅 Amphenol、TE、Entegris 讀過 SEC 8-K 原文。

## 部署

### GitHub Pages

1. 建立公開倉庫（免費帳號的 GitHub Pages 需要公開倉庫）。
2. 將 `index.html` 放在倉庫根目錄並推送到 `main`。
3. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，儲存。
4. 等待一到兩分鐘，網址為 `https://<帳號>.github.io/<倉庫名>/`。

發佈後整份報告與公司表對所有人公開，搜尋引擎也能找到。

### 嵌入 Google Sites

在 Sites 編輯頁選「嵌入 → 嵌入程式碼」，貼上 `index.html` 的全部內容，插入後把嵌入方塊拉到整頁寬度並加高。若貼上時被拒絕，可能超過大小限制，需把報告全文拆成另一個檔案。
